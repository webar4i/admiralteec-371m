# Адмиралтеец 371М — справочная 3D-модель

Просмотрщик: https://webar4i.github.io/admiralteec-371m/

379 выбираемых элементов и групп: набор корпуса, бимсы, палуба,
надстройка, интерьер, механизмы и пространственные схемы систем.
Вращение, разрезы, слои, разнесение сборки, габариты выбранного объекта,
линейка и экспорт. Предварительные сценарии загрузки и мощности.

**Это справочная реконструкция, не рабочий строительный проект.**
Сечения набора и сварные соединения не подтверждены; размеры в интерфейсе
не являются размерами заготовок. Полная прочность и остойчивость,
подбор винта и фактическая тяга не подтверждены. Соответствие существующему
повреждённому катеру нужно устанавливать по обмерам и документации.

Основа: опубликованный прогулочный вариант [SeaTech 371М](https://www.seatech.ru/rus/project/tune/371m/haracter.htm).
Все библиотеки, шрифты и геометрия встроены в index.html; для работы нужен WebGL.
Внешние ссылки на источники требуют подключения к интернету.

Публикация: готовый HTML из локального проекта. GitHub Pages использует
ветку main, корень репозитория, без Jekyll. Для обновления заменить index.html
следующей проверенной сборкой и отправить изменения в main.

Лицензии используемых библиотек и шрифта: THIRD_PARTY_NOTICES.txt и Manrope-OFL.txt.
